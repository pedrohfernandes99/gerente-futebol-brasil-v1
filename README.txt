GERENTE DE FUTEBOL BRASIL V1 — MOBILE READY / PWA

TESTE RÁPIDO NO ANDROID
1. Extraia o ZIP.
2. Abra index.html no Chrome para um teste visual/local.

INSTALAR COMO APP (RECOMENDADO)
A instalação PWA precisa que os arquivos estejam hospedados em HTTPS (GitHub Pages, Netlify, Cloudflare Pages etc.).
Depois de abrir o endereço no Chrome Android, toque em "Instalar jogo" quando o botão aparecer ou use Menu > Adicionar à tela inicial / Instalar app.

MELHORIAS MOBILE
- menu inferior fixo e rolável;
- topo compacto;
- botões e campos maiores para toque;
- campo tático com arrastar por toque/pointer;
- telas, modais e criação do clube responsivos;
- placares ao vivo posicionados acima do menu inferior;
- suporte PWA e cache offline após a primeira abertura hospedada.

O mesmo pacote continua funcionando no computador.
